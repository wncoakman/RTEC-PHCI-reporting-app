Reporting App SOP

  1. Verify this link is opened in the Safari browser.
  2. Tap the Share icon → Add to Home Screen.
  3. Open the app and follow the prompts for a scheduled PHCI IPM inspection visit — or for any finding that's a tech-generated lead needing arborist action, select Arborist Review Required on the Save Finding screen.
  4. Save the report PDF to the device, then upload it to the SingleOps visit's attachments.
  5. Email the report to the client from the SingleOps visit header using the "@PHC Service Report Email" template.
  6. Additionally email the Arborist and CSR using the "PHC Tech Generated Lead" email template, including any relevant details about a scheduled arborist visit or proposal needed.
